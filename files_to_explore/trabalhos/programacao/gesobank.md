### Descrição
**Projeto acadêmico que visa simular o desenvolvimento de um serviço financeiro, com foco na segurança de dados por meio de criptografia (AES, RSA)**

---

### Sobre o Projeto:
GesoBank é um estudo de desenvolvimento de uma API financeira, com foco no aprendizado de métodos de `criptografia` e `segurança` para o mercado de trabalho.
O projeto está dividido em duas grandes partes: `BackEnd` e `Connection`.

#### Back End
- **Routes -** Definição das rotas de conexão usando Flask
- **Connections -** Recebimento e retorno de respostas às requisições das rotas
- **Services -** Responsável pela lógica geral de todas as funcionalidades do sistema
- **Models -** Estrutura básica das classes e banco de dados
- **Cryptography -** Local dos métodos de criptografia e ambientes

#### Connection
- Um terminal de console simples para utilizar o backend
